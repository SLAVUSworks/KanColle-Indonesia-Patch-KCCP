## 🚢 Tentang KanColle

<img src="https://raw.githubusercontent.com/Oradimi/KanColle-English-Patch-KCCP/master/ID-patch/kcs2/img/title/title_main.png/patched/title_main_004.png" align="right" width="280" alt="KanColle Title Screen"/>

**Kantai Collection** (艦隊これくしょん), atau dikenal sebagai **KanColle** (艦これ), adalah permainan daring sosial berbasis web buatan **Kadokawa Games** yang diluncurkan pada **23 April 2013**.

Pada April 2015, permainan ini tercatat memiliki lebih dari **3 juta pengguna terdaftar** dan hanya dapat dimainkan di Jepang. Adaptasi anime-nya mulai tayang pada Januari 2015, diikuti oleh sekuel dan film animasi yang dirilis pada November 2016.

<br clear="right"/>

## 🛠️ Tentang KC Patch

**KC Patch Indonesia** adalah proyek modifikasi untuk web game KanColle yang menghadirkan antarmuka dalam **Bahasa Indonesia** — memungkinkan para Teitoku Indonesia menikmati game dengan lebih nyaman.

> Patch ini menggunakan [KanColle-English-Patch-KCCP](https://github.com/Oradimi/KanColle-English-Patch-KCCP) sebagai framework. Proses instalasi dan patching mengikuti panduan yang sama.

**Fitur utama:**

- ✅ Antarmuka game dalam Bahasa Indonesia
- ✅ Teks menu, nama item, dan deskripsi diterjemahkan
- ✅ Kompatibel dengan update game terkini
- ✅ Panduan instalasi tersedia untuk Windows & Linux
